# Пиктограммы медицинской инфраструктуры

Плоский SVG-набор для карты MapLibre и панели слоёв.

| Файл | Категория | Цвет |
|---|---|---|
| `hospital.svg` | Больницы | `#2563EB` |
| `polyclinic.svg` | Поликлиники | `#059669` |
| `fap.svg` | ФАП | `#D97706` |
| `ambulatory.svg` | Амбулатории | `#0891B2` |
| `maternity.svg` | Родильные дома | `#BE185D` |
| `consultation.svg` | Консультационные центры | `#EA580C` |
| `rehabilitation.svg` | Реабилитация | `#7C3AED` |
| `health-post.svg` | Здравпункты | `#64748B` |

Все файлы используют `viewBox="0 0 32 32"`, не содержат градиентов,
растровых вставок и внешних шрифтов. Для карты рекомендуемый размер —
22–26 px, для панели слоёв — 36–40 px.
