# Интерактивный атлас смертности Амурской области

Самостоятельная статическая версия интерактивного атласа за 2023–2025 годы.
Сборка содержит только данные и визуализации Амурской области и не зависит от
общего портала или материалов других регионов.

## Состав

- Treemap МКБ-10;
- Heatmap «территория × причина»;
- диаграмма изменения рангов между годами или полами;
- возрастно-половая пирамида;
- медианный возраст и интервалы;
- интерактивная карта муниципалитетов и населённых пунктов;
- Dotogram территорий;
- интерактивная карта медицинской инфраструктуры:
  - 417 учреждений с независимым включением восьми типов;
  - совокупные изохроны транспортной доступности от больниц 20 и 60 минут;
  - 29 муниципальных территорий;
  - 632 населённых пункта с размером знака по населению переписи 2021 года;
- локальные таблицы контроля и агрегированные выгрузки.

## Запуск

Основные аналитические диаграммы можно открыть непосредственно через `index.html`.
Для корректной загрузки инфраструктурной карты нужен локальный HTTP-сервер,
например:

```powershell
python -m http.server 8765
```

После запуска откройте `http://127.0.0.1:8765/`. Серверная база данных не нужна:
слои загружаются как статические файлы.

Для GitHub Pages файлы нужно разместить в корне отдельного репозитория и включить
публикацию ветки, содержащей `index.html`.

## Структура

```text
index.html
assets/
  site.css
  site.js
  infrastructure-map.css
  infrastructure-map.js
  icons/
    medical-facilities/
      *.svg
data/
  infrastructure-data.js
scripts/
  build_infrastructure_data.py
  patch_atlas_for_infrastructure.py
  test_infrastructure_map.cjs
tables/
  class_year.csv
  municipality_class.csv
  quality.json
manifest.json
.nojekyll
```

В HTML встроены только обезличенные аналитические признаки. Идентификаторы
записей о смерти, адреса и персональные данные не публикуются.

Инфраструктурная карта работает в Web Mercator (EPSG:3857). Исходные векторные
слои при сборке переводятся в GeoJSON EPSG:4326 — это стандартный формат обмена
для MapLibre; проецирование на экран выполняет картографический движок.

Медицинские учреждения используют отдельные плоские SVG-пиктограммы. Кластеры
показываются сегментированными кольцами: толщина кодирует количество объектов,
секторы — реальные доли типов, а точка внутри — доминирующий тип. Наведение
показывает точный состав, клик приближает карту до распада кластера.
