# Интерактивный атлас смертности Амурской области

Самостоятельная статическая версия интерактивного атласа за 2023–2025 годы.
Сборка содержит только данные и визуализации Амурской области и не зависит от
общего портала или материалов других регионов.

## Состав

- Treemap МКБ-10;
- Heatmap «территория × причина»;
- диаграмма изменения рангов между годами или полами;
- возрастно-половая пирамида;
- медианный возраст и интервалы;
- интерактивная карта муниципалитетов и населённых пунктов;
- Dotogram территорий;
- локальные таблицы контроля и агрегированные выгрузки.

## Запуск

Для локального просмотра достаточно открыть `index.html` в современном браузере.
Сервер, база данных и установка сторонних библиотек не требуются.

Для GitHub Pages файлы нужно разместить в корне отдельного репозитория и включить
публикацию ветки, содержащей `index.html`.

## Структура

```text
index.html
assets/
  site.css
  site.js
tables/
  class_year.csv
  municipality_class.csv
  quality.json
manifest.json
.nojekyll
```

В HTML встроены только обезличенные аналитические признаки. Идентификаторы
записей о смерти, адреса и персональные данные не публикуются.
