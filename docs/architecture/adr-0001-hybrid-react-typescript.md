# ADR-0001: постепенная гибридная миграция React + TypeScript

- Статус: принято
- Дата: 2026-08-18

## Контекст

Атлас является статическим приложением GitHub Pages. Данные и часть логики встроены в крупный HTML-файл, визуализации используют общий изменяемый объект состояния, а карты MapLibre и SVG-графики управляются императивно. Полная перепись создаёт высокий риск регрессий карт, фильтров и расчётов.

## Решение

1. Использовать Node.js только как build-time окружение.
2. Подключать React по принципу островов, начиная с оболочки и панелей управления.
3. Ввести TypeScript-контракты раньше переноса визуализаций.
4. Связать React и legacy-код через минимальный событийный адаптер.
5. Не передавать React полный массив наблюдений до выделения отдельного слоя данных.
6. Сохранить MapLibre как самостоятельный императивный движок.
7. Переходить к следующему этапу только после проверки данных, typecheck, unit-тестов, browser smoke-теста и профиля производительности.

## Последствия

Положительные:

- работающий атлас остаётся доступным на каждом этапе;
- типы и тесты появляются до крупных изменений интерфейса;
- можно переносить вкладки независимо;
- сохраняется простой статический хостинг.

Ограничения:

- в переходный период одновременно существуют legacy- и React-слои;
- требуется строго контролировать единственный источник состояния;
- production-бандл React временно хранится в репозитории до перевода GitHub Pages на сборку `dist/`.
